Security-Betriebshandbuch

AI-Python · AGENTS.md · HTTP-MCP · Secrets/Logs · SBOM · Störung
Gültigkeit: FreeCAD AI 0.23.1-alpha, FreeCAD ≥1.0, Python ≥3.11. Eine vollständig getestete Hostmatrix ist noch nicht freigegeben.

AI-Python sicher verwenden

  1. Bevorzugen Sie strukturierte Werkzeuge.
  2. Aktivieren Sie Allow AI Python nur für einen konkreten Bedarf und lesen Sie die Warnung.
  3. Prüfen Sie bei jedem Aufruf den exakten Code. Abbrechen verändert das Dokument nicht.
  4. Eine grüne Vorprüfung ist nur ein Kompatibilitätssignal, keine Isolation. Genehmigter Code hat Benutzerrechte.
  5. Der Schalter wird nicht gespeichert und ist vom Dangerous Mode getrennt.

Projektanweisungen

Eine AGENTS.md oder FREECAD_AI.md wird vom Dokumentverzeichnis nach oben und anschließend im FreeCAD-AI-Konfigurationsverzeichnis gesucht. Prüfen Sie Vorschau, kanonische Root, Quelle, Manifest, Fingerprint und Inhalt. Trust and send gilt nur für exakt diesen Fingerprint; Ignore sendet keinen Projekttext; Cancel sendet nichts. Absolute Pfade, .., Symlink-Ausbruch, nicht reguläre/ungültige/zu große Dateien, Zyklen und zu tiefe Includes werden verworfen.

HTTP-MCP

Der Standardtoken liegt in <FreeCADAI dir>/mcp_server.token und wird privat erzeugt. Lesen Sie ihn lokal und konfigurieren Sie im Client:

Authorization: Bearer <Inhalt der Token-Datei>

MCP_TOKEN_FILE darf auf eine bereits vorhandene, benutzereigene reguläre Datei mit restriktiven Rechten zeigen. Sie wird nicht verändert. Alle HTTP-Routen benötigen Authentisierung. Der Server bindet nur Loopback oder genau eine private/link-lokale numerische Adresse und begrenzt Rate/Parallelität. execute_code wird über HTTP nie veröffentlicht.

Restgefahr: HTTP im privaten LAN verschlüsselt das Token nicht. Ohne separat geschützten Transport keinen LAN-Betrieb mit vertraulichen Dokumenten verwenden. Internet-Bindung ist nicht unterstützt.

Secrets, Rechte und Logs

Verwaltete POSIX-Verzeichnisse/Dateien werden mit 0700/0600 gehärtet und atomar geschrieben. Literal-API-Schlüssel werden verlustfrei in private Dateien migriert; file: und cmd: bleiben explizite Benutzerfunktionen. Unter Windows ist keine vollständige ACL-Garantie belegt. Standard-Sitzungslogs speichern Toolname, Erfolg, Dauer, Turn und Fehlerklasse, aber keine Nachrichtentexte, Argumente oder Ergebnisse. Full-Logging muss bewusst aktiviert werden und bleibt trotz Redaction sensibel.

Runtime-Inventar

Der Generator muss innerhalb der tatsächlichen FreeCAD-Laufzeit ausgeführt werden:

"$FREECAD_AI_SUPPORTED_FREECADCMD" -c "import sys; from freecad_ai.runtime_inventory import main; sys.exit(main(['--output','build/freecad-ai-runtime.cdx.json']))"

Er bricht ab, wenn Add-on, FreeCAD, Python, PySide oder Qt keine sichere Version liefern. Danach das JSON gegen CycloneDX 1.5 validieren und mit einem aktuellen Scanner wie Grype oder Trivy prüfen. Ein leerer PyPI-Abhängigkeitsscan ist kein Host-Sicherheitsnachweis.

Störung und Rollback

  • Bei Token-/Bind-/TLS-/Pfadfehler nicht auf unauthentifizierte oder ungeprüfte Modi ausweichen.
  • Bei vermutetem Tokenabfluss Serverzugang stoppen, Tokendatei kontrolliert rotieren und Clients neu konfigurieren; Tokens nie in Tickets/Logs kopieren.
  • Migrierte Secret- oder Trustdateien nicht löschen. Restriktive Rechte nicht lockern.
  • Wenn HTTP nicht nutzbar ist, STDIO als dokumentierten Kompatibilitätspfad erwägen.
  • Vor Prozessstopp/-neustart den exakten Prozess bestimmen und Genehmigung einholen.
